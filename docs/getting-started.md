# Getting started

1. [Open PolyGlot Arcade Tutor](https://pat.pcssiirobotics.org/) and choose one of the four games. You can switch games later without losing lesson progress in another game.
2. Select **Play game** to try the completed reference game, or **Start learning** to open Step 1.
3. Read the lesson and find the `TODO` comments in the starter code.
4. Choose **JavaScript**, change the code, and select **Run Canvas** to see the result.
5. Select **Run Tests** for feedback. If you are stuck, use **Stuck on a TODO?** for one hint at a time or a read-only worked example.
6. Continue to the final step for your game. Select **Play game** or **Download game** for the completed reference game.

Your editor changes are separate from the reference game download. **Download my code** saves the code currently in your editor; **Download game** saves the completed playable game as an HTML file.

Python and Java show code examples and simulated previews. They do not compile or execute in the browser. Use JavaScript when you want your edits to run on the canvas.

The app is designed for desktop and mobile. On touch devices, use the on-screen controls when playing a game.

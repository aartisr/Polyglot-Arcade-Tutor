# Frequently asked questions

## Who created PolyGlot Arcade Tutor?

[Aarti S Ravikumar](https://ai-aarti.com/) created the project. See the [citation page](citation.html) for the preferred credit.

The project was made for Hack Club Haven, hosted by [PCSS II Robotics Club](https://pcssiirobotics.org/).

## What if I do not know how to fill a `TODO`?

Use **Stuck on a TODO?** in the lesson panel. It reveals hints one at a time and a worked example without replacing your editor code.

## Do Python and Java run in the browser?

No. JavaScript runs in the browser canvas. Python and Java are comparison views with simulated previews and code checks.

## Can I play the finished game without completing all lessons?

Yes. Choose **Play game** from the home screen. The reference game can also be opened from the final lesson.

## What is the difference between the two downloads?

**Download game** saves the completed reference game as a standalone HTML file. **Download my code** saves the current editor text as a source file.

## Can I add another game?

Yes. Add a `GameDefinition` to the [registry](add-a-game.html). The interface and search guide derive their game lists from it.

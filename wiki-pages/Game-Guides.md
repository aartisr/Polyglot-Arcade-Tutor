# Game Guides

## Neon Dungeon: Rogue Crawler

Learn canvas drawing, movement, wall collision math, and a scoring game loop. [Start Step 1](https://pat.pcssiirobotics.org/tutor/step-1?game=neon-dungeon).

## Cyber Invaders: Space Grid

Learn ship drawing, strafing and lasers, alien collision math, and a game loop with bunkers and scoring. [Start Step 1](https://pat.pcssiirobotics.org/tutor/step-1?game=cyber-invaders).

Each game has four lessons. The [Pages lesson index](https://aartisr.github.io/Polyglot-Arcade-Tutor/games.html) links to every step, and the [live lesson guide](https://pat.pcssiirobotics.org/discover/) describes each step for readers and search engines.

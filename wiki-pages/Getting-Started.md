# Getting Started

1. [Open the tutor](https://pat.pcssiirobotics.org/) and choose a game.
2. Select **Play game** to try the reference game or **Start learning** for Step 1.
3. Fill the marked `TODO` tasks in the editor. Use **Stuck on a TODO?** for progressive hints and a read-only worked example.
4. Choose JavaScript and **Run Canvas** to see your edits. Select **Run Tests** for feedback.
5. Continue to Step 4, then play or download the finished reference game.

**Download game** saves a playable HTML file. **Download my code** saves your editor text. Python and Java are comparison views; they do not execute in the browser.
